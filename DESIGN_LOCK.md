# UMLTD.UK — DESIGN LOCK

**Design version:** DESIGN-LOCK-1.0  
**Locked:** 15 September 2026

This file defines the visual source of truth for UMLTD.UK.

## Locked rules

- `assets/styles.css` is the single site-wide stylesheet and MUST NOT be restyled, replaced, or appended with competing visual overrides unless the owner explicitly says **UNLOCK DESIGN**.
- Content edits may change wording and add content using the existing component classes, but must preserve the existing visual system.
- The home hero uses the full network image with the copy on the left. There is **no floating service box** in the hero.
- Hero typography, widths, spacing, colour system, buttons and background crop are locked.
- Interior page heroes use the same network image treatment and the locked large headline scale.
- Main section headings alternate position: first content section right, next left, then right, etc.
- Alternate sections use the lighter charcoal/green surface defined in `styles.css` to break up the dark page.
- Service/card index numbers use the large numeric treatment defined in `styles.css`.
- Navigation, responsive breakpoints, card radii, borders and footer composition are locked.
- `assets/background.png` remains a CSS background, never an inline content image.
- `assets/umltd-logo.svg` remains the site logo.
- Mobile may reflow to a single column; it must not introduce horizontal overflow.

## Allowed without unlocking

- Correcting copy, spelling or factual details.
- Adding additional pages using the existing hero, section, card and footer components.
- Adding or removing content blocks while preserving the locked CSS classes and alternation pattern.
- Updating contact or regulatory details when supplied by the owner.

## Requires explicit UNLOCK DESIGN instruction

- Changing `assets/styles.css` visual rules.
- Reintroducing a floating hero card/panel.
- Changing the hero image/crop/composition.
- Changing global typography, colours, radii, navigation geometry or section alternation.
- Replacing the dark/lighter alternating surface system.
